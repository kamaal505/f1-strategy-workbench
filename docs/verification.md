Python 3.12.13, uv 0.11.28, macOS arm64; existing `.venv` retained.

- `uv run --locked pytest --disable-socket --allow-unix-socket`: **87 passed**, 141.61 seconds. Numerical thread limits were set to one.

- Installed the wheel into the existing environment with `uv pip install --no-deps --reinstall`; imported from `site-packages`, outside the project working directory. Packaged snapshots/model opened, copied into a verified writable runtime root, and completed an actual comparison and bounded report subprocess.
- Actual CLI: synthetic generation, training, snapshot integrity, replay, comparison and HTML report rendering. Training uses 200 parameter replicates and the mandatory assumption grid.
- Actual browser: CLI/UI analysis identity agreement; changed pit loss; advanced completed lap; visibly separate hindsight; missing telemetry; synthetic rain/red prefix returned unavailable statistics. Public mode excluded all three unauthorized real races.
- Final public-mode synthetic report downloaded through an authorized direct-byte response, without a reusable `/media` URL. Opened downloaded HTML with networking disabled: two Plotly charts, no browser errors.
- Read-only scientific/security reviews completed; evidence-backed defects were corrected and covered by the final behavioral run.
